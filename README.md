# Simple Task Tracker Application

## Project Description
The Simple Task Tracker is a lightweight, responsive web application designed to help users organize their daily schedules and stay productive. It provides a clean and modern user interface to manage tasks efficiently without needing complex account set-ups or heavy server-side processing. The system addresses the common problem of everyday disorganization by offering a fast, client-side tool that loads instantly in any modern web browser.

## Features
* **Task Creation:** Users can add new tasks with a text description via a clean input form.
* **Status Toggling:** Tasks can be marked as completed or active dynamically with a single click.
* **Persistent Storage:** Tasks are securely saved directly in the user's browser using the Web Storage API (localStorage), ensuring data is kept even after reloading the page.
* **Task Removal:** Users can permanently delete tasks from their tracking list once they are no longer relevant.
* **Responsive Layout:** The interface adapts gracefully to mobile phones, tablets, and desktop computers.

## Technologies Used
* **HTML:** Utilized for building the semantically structured interface layouts and form inputs.
* **CSS:** Used for styling custom interactive states, smooth transitions, and core layout elements.
* **JavaScript:** Implemented for DOM manipulation, client-side event handling, and data mapping logic.
* **Bootstrap :** Leveraged for modern UI components, grid layouts, and rapid mobile-first responsive utility styling.

## Installation and Usage
Follow these basic steps to run and use the project locally on your machine:

1. Clone this repository or download the source code zip archive to your local environment.
2. Navigate into the main project folder.
3. Open the `index.html` file using any standard modern web browser (such as Google Chrome, Mozilla Firefox, or Microsoft Edge). No server installation or build steps are required.
4. Type your task into the text box and click the "Add Task" button to begin using the tracker.
